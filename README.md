# Final Bounce

Site officiel de Final Bounce, publié sur
[finalbounce.studio](https://finalbounce.studio/).

## Source de vérité

Ce dépôt GitHub est la source de référence du site. Les futurs exports Webflow
ne doivent pas remplacer directement les fichiers de ce dépôt.

## Organisation actuelle

- `index.html` : accueil
- `enregistrement.html` : service d’enregistrement
- `mixage.html` : service de mixage
- `cdn.prod.website-files.com/` : styles, scripts, polices et images issus de
  l’export Webflow
- `assets.itsoffbrand.io/` : médias du modèle d’origine à remplacer

## Publication

La branche `main` correspond à la version publique. Toute évolution doit être
préparée et validée sur une branche dédiée avant d’être fusionnée.
